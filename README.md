# Simple Calculator (Java)
This project is a basic calculator program developed in Java as part of my Computer Science learning practice.

## Features
- Performs basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division

## Concepts Used
- Java syntax
- Conditional statements
- User input handling
- Arithmetic operators
- Problem solving

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To practice fundamental programming concepts such as variables, conditionals, and mathematical operations.
This project helped strengthen my understanding of how user input is processed and how basic logic is implemented in Java programs.
